Entrants hand in a single out-of-office email auto-reply of at most 200 characters. It has to be painfully honest about the sender's absence, inbox or enthusiasm, and still polite enough that a manager would let it stand. A house judge compares the replies two at a time in private rounds, weighing honesty first, then politeness, then the turn of phrase, and the most honest reply that still sounds professional takes the reward.

## Run it

```sh
python3 main.py
```
